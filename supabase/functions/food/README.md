# `food` Edge Function: the engine

Powers "Describe a meal". Grounds an LLM on three food sources and does the
portion arithmetic in code, so a number is either measured or visibly flagged.

| action       | body                                                 | returns                                                        |
| ------------ | ---------------------------------------------------- | -------------------------------------------------------------- |
| `health`     | `{ action: 'health' }`                               | `{ ok, provider, model, usda, llm }`; `llm` explains a failure |
| `parse`      | `{ action: 'parse', text }`                          | `ParsedMeal`: items, macros, confidence, one-tap alternates    |
| `transcribe` | `{ action: 'transcribe', audio, mime: 'audio/wav' }` | `{ text }`: a spoken meal as text                              |

Both require a signed-in user. Requests are accepted only from the origins in
`ALLOWED_ORIGINS`.

## Pipeline

1. `structureMeal`: the LLM splits the text into foods, servings and any stated
   amount (`grams`).
2. Candidates from the curated Indian dish table (`_indian-foods.ts`), IFCT 2017
   (`ifct.ts` over `_ifct.ts`) and USDA FoodData Central.
3. `judgeCandidates`: the LLM picks a candidate and gives an independent
   estimate.
4. `portion.ts`: per-100 g multipliers from stated weights. `ifct.ts`:
   raw-to-cooked yields for rice and dals, offered as both readings.
5. Confidence and a reason per item. A degraded run (USDA unavailable, missing
   judgement) is flagged and never cached.

Results are cached for 7 days in `food_cache`, keyed by `ENGINE_VERSION`, model
and text. Bump `ENGINE_VERSION` whenever parse output changes.

## Files

| File               | What it is                                           |
| ------------------ | ---------------------------------------------------- |
| `index.ts`         | handler, LLM calls, candidate merge, confidence      |
| `portion.ts`       | stated amount to serving multiplier                  |
| `ifct.ts`          | IFCT search, aliases, cooked yields                  |
| `_ifct.ts`         | generated from IFCT 2017 by `scripts/import-ifct.py` |
| `_indian-foods.ts` | generated by `scripts/sync-indian-foods.mjs`         |

Tests for `portion.ts`, `ifct.ts` and the IFCT table live in `src/lib/food/`.
